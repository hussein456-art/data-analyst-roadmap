DATA ANALYST — ARABIC ROADMAP

خريطة طريق تحليل البيانات

امشِ من محطة لمحطة. لا تنتقل للمرحلة التالية إلا بعد تحقيق شروط الخروج في نهاية كل محطة.

الهدف النهائي: تكون قادرًا على أخذ Dataset حقيقية، تنظيفها، استخراج Insights بـ SQL/Python، بناء Dashboard احترافي بـ Power BI، ثم عرض المشروع كـ Portfolio.
1

Excel + عقلية محلل البيانات

المدة المقترحة: 3–4 أسابيع

اتعلم

  • Tables, Sort/Filter, IF, SUMIFS, COUNTIFS, XLOOKUP/VLOOKUP
  • تنظيف البيانات: duplicates, blanks, text/date problems
  • Pivot Tables + Pivot Charts + basic dashboards
  • أساسيات الإحصاء: mean, median, standard deviation, correlation
  • قبل كل تحليل: ما السؤال؟ ما الـ KPI؟ وما القرار الذي ستساعد البيانات فيه؟

الكورس الأساسي

كورس تحليل البيانات بالإكسل — اتعلم مع العسالYouTube Playlist
لا تنتقل قبل أن:
تعمل تقرير Excel من Dataset حقيقية وتشرح 3 Insights منه.
2

SQL + قواعد البيانات

المدة المقترحة: 4–5 أسابيع

اتعلم بالترتيب

  • SELECT → WHERE → ORDER BY → DISTINCT
  • CASE WHEN + NULL handling
  • GROUP BY + HAVING + aggregate functions
  • JOIN: INNER / LEFT / RIGHT
  • Subqueries + CTEs
  • Window Functions: ROW_NUMBER, RANK, SUM/AVG OVER
  • حل مسائل SQL باستمرار، وليس مشاهدة الكورس فقط

الكورس الأساسي

SQL للمبتدئين بالعربي — Korsat X ParmagaYouTube Playlist
لا تنتقل قبل أن:
تحل 30–50 سؤال SQL وتقدر تعمل JOIN + GROUP BY + Window Function بدون نسخ الحل.
3

Python للـ Data Analysis

المدة المقترحة: 5–7 أسابيع

اتعلم

  • Python basics: variables, lists, dictionaries, loops, functions
  • NumPy basics
  • Pandas: read_csv, info, describe, loc/iloc, groupby, merge
  • Cleaning: missing values, duplicates, types, strings, dates
  • Visualization: Matplotlib / Seaborn / Plotly basics

مصادر عربية

كورس تحليل البيانات باستخدام Python — نورهان زيديتضمن Pandas, Seaborn, Matplotlib, Plotly, NumPy ومشاريع عملية شرح كامل لبايثون لتحليل البيانات — Alvanguardشرح مختصر ومفيد كبداية تطبيقية
لا تنتقل قبل أن:
تفتح CSV، تنظفه بـ Pandas، تعمل 5 تحليلات و5 رسومات وتشرح النتائج.
4

EDA — Exploratory Data Analysis

تُطبَّق مع Python، وليست مرحلة مشاهدة كورس فقط

طريقة التفكير

  • افهم business question قبل لمس البيانات
  • اعرف شكل البيانات والـ data types
  • Missing values + duplicates + outliers
  • Univariate / bivariate analysis
  • Correlation بدون افتراض أن الارتباط يعني السببية
  • اكتب Insights بصيغة: ماذا حدث؟ لماذا قد يكون حدث؟ وما القرار المقترح؟

مخرج المرحلة

  • Notebook مرتب
  • Data cleaning واضح
  • EDA charts
  • صفحة Conclusions
اختبارك:
أعطِ نفسك Dataset لم ترها من قبل وحللها من الصفر خلال جلسة عمل كاملة.
5

Power BI — Visualization + BI

المدة المقترحة: 4–6 أسابيع

اتعلم بالترتيب

  • Import + Power Query
  • Data cleaning & transformation
  • Data model + relationships
  • Measures vs calculated columns
  • DAX basics ثم DAX عملي
  • KPIs, slicers, drill-through, tooltips
  • Dashboard design: hierarchy, whitespace, useful visuals فقط

الكورس الأساسي

كورس Power BI — اتعلم مع العسالYouTube Playlist تعلم Power BI من الصفر — أكاديمية العسالفيديو/مدخل حديث للكورس
لا تنتقل قبل أن:
تبني Dashboard من Dataset خام وتوصل من Power Query إلى Data Model ثم DAX ثم التقرير النهائي.
6

Portfolio Projects — أهم محطة

المدة المقترحة: 4–6 أسابيع، وتستمر بعدها

اعمل 3 مشاريع

  • Project 1 — Sales: Excel + Power BI
  • Project 2 — E-commerce: SQL + Power BI
  • Project 3 — Customer/HR: Python + EDA + Power BI

كل مشروع لازم يحتوي

  • Business question
  • Raw data → cleaning
  • Analysis
  • Dashboard
  • 5–10 Insights
  • Recommendations
  • README مرتب + screenshots
شرط النجاح: شخص آخر يفتح مشروعك ويفهم المشكلة، ماذا اكتشفت، وما القرار المقترح بدون أن تشرح له كل خطوة شفهيًا.
